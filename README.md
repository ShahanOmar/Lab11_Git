\f0\fs24 \cf0 # Storage Requirement Estimator\
\
## Purpose\
A lightweight Python program designed to estimate required data storage capacity based on the total number of entries and average entry file sizes.\
\
## How to Run\
Execute the script from your terminal using:\
```bash\
python storage_estimator.py\
```\
\
## Example Input & Output\
```text\
Enter total number of records: 10000\
Enter average size per record (in bytes): 500\
\
--- Estimation Results ---\
Total Size: 5,000,000 Bytes\
Total Size: 4.77 MB\
Total Size: 0.0047 GB\
```\
